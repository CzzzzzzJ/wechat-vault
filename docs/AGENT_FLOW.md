# Agent 问答流程

用户只输入一次需求，例如“帮我找今天需要跟进的事”。

1. **理解需求**：Codex 提取日期、分析目标和明确提到的会话名。此时只发送用户问题及日期。
2. **确定范围**：本地程序验证结构化结果，限定当前账号。名称有歧义时在对话里提供候选，不要求重新填表。
3. **读取材料**：复用 Skill 查询已发布快照。宽泛需求按本人参与量选取最多 5 个会话；单日、1000 条/会话、总计 60000 字符的限制在范围卡片中说明。
4. **展示范围**：对话内呈现日期、会话名、消息数及限制。“查看消息依据”默认折叠，不弹窗、不重复询问问题。
5. **开始分析**：用户点击“用这些消息分析”，将该卡片对应的固定材料发送到 Codex。原始数据库与密钥留在本机。
6. **给出结果**：按话题、重要信息、待办、待确认事项回答，并附消息引用。负责人和时间缺少依据时明确标注。

只问数量排行时直接返回本地统计，跳过正文读取及发送。切换账号、日期或取消会使待发送卡片失效；无匹配时不选择无关聊天替代。

当前不支持跨日分析、语音转写、图片理解、自动执行待办或长期问答记忆。广泛需求属于有界筛选，不能视为全账号穷尽检索。
